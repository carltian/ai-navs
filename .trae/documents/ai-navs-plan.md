# AI 导航站开发计划

## 项目概述
基于现有的 Next.js 项目，打造一个功能完善、界面美观的 AI 导航站，汇集各类 AI 工具和平台。

## 现有分析

### 已有功能
- ✅ 左侧固定导航栏，支持分类跳转
- ✅ 搜索功能
- ✅ 卡片展示布局
- ✅ 响应式设计基础

### 主题色系
- **主色调**：蓝色系 (blue-500)
- **背景色**：白色/黑色（支持深色模式）
- **导航栏**：slate-300（灰色）
- **卡片背景**：白色

### 数据结构
```json
{
  "title": "分类名称",
  "cards": [
    {
      "id": "唯一标识",
      "name": "工具名称",
      "desc": "工具描述",
      "img": "图片路径",
      "link": "跳转链接"
    }
  ]
}
```

## 开发计划

### 第一阶段：数据完善

#### 1.1 完善 data.json 数据
为每个分类添加丰富的 AI 工具数据：

**AI热门工具**
- 豆包、DeepSeek、ChatGPT、Claude、千问、Kimi、文心一言

**AI对话工具**
- ChatGPT、Claude、豆包、Kimi、通义千问、文心一言、智谱清言

**AI编程工具**
- GitHub Copilot、Cursor、Codeium、Tabnine、通义灵码、CodeGeeX

**AI绘画**
- Midjourney、Stable Diffusion、DALL-E、文心一格、通义万相、即梦

**AI新闻**
- 36氪、机器之心、新智元、量子位、AI科技评论

**大模型API**
- OpenAI API、DeepSeek API、通义千问API、文心一言API、智谱API

**Agent工具**
- Coze、Dify、FastGPT、GPTs、AgentGPT

#### 1.2 准备图片资源
- 在 `public/img/` 目录下存放各平台的 logo 图片
- 图片格式：PNG 或 JPG
- 推荐尺寸：120x120 或 200x200

### 第二阶段：页面优化

### 第三阶段：功能增强

#### 3.1 添加分类筛选

- 添加分类计数显示

#### 3.4 添加统计功能
- 统计工具总数
- 统计各分类数量

### 第四阶段：样式美化

#### 4.1 统一主题色

#### 4.2 添加动画效果

#### 4.3 响应式优化
- 优化移动端导航（抽屉式）
- 优化平板端布局
- 优化卡片网格布局

### 第五阶段：SEO 和性能优化

#### 5.1 SEO 优化

- 优化页面标题

#### 5.2 性能优化

## 技术栈
- **框架**：Next.js 15
- **样式**：Tailwind CSS
- **UI 组件**：MUI (Material-UI)
- **图标**：MUI Icons
- **语言**：TypeScript

5. 确保响应式设计在各设备上正常显示
